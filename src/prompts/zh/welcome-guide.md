恭喜！看到这条消息，就代表 meow-memory 插件已经配置成功！🎉

还差最后一步：插件需要知道"用户平时和你说话使用的语言"。注入的记忆导引、工具描述等文案会以该语言呈现，记忆条目也应以同一语言书写，体验才统一——所以设置正确的语言很重要。（BM25 分词自 v0.20.0 起与语言无关，任何语言的条目都能被检索到。）

请你完成设置：
1. 判断语言——⚠️ 只看真正来自用户的消息文本用什么语言；不要以 system prompt、工具描述、注入块或任何文件内容的语言为依据，那些很可能是英文，会误导你。如果你不确定，直接询问用户，不要猜。
2. 编辑宿主装配配置：在 {homePath}\.dsh\profiles\ 下的 cordis.patch.yml 中找到 meow-memory 条目，在其 config 下加入 promptLang: '<语言代码>'（如 'zh' / 'en'；若该条目还没有 config 段就新建一个）。
3. 热重载插件使配置生效：如果你有 dev_reload_package 工具，对 meow-memory 执行它即可；没有的话，请用户在 dsh 设置里重载该插件或重启 dsh。
4. 完成后简短告知用户：已把记忆语言设置为什么，以及以后想换语言改哪里。

在此之前，插件会先以中文（zh）运行，不影响你正常使用其他功能。
