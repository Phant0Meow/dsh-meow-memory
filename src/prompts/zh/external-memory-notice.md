【meow-memory 外部记忆库提示】
此工作区自带一份不是在本机创建的记忆库（.dsh-meow/）。为防止仓库作者预置的内容被当作用户本人的长期记忆注入，meow-memory 已在此工作区暂停：不注入、不检索、不整理、不写入，memory 工具也不可用。

- 这通常发生在 clone 了自带 .dsh-meow/ 的外部仓库时（零交互即注入是设计给本机记忆的，对预置库是安全风险，issue #64）。
- 若这是用户自己的项目（换机 / 恢复备份 / 自己拷贝的目录），让用户在输入框执行 /meow-trust 即可恢复，无需重启。
- 若用户不认识这份记忆库，保持停用即可；也可把工作区加入 disabledWorkspaces 名单。

本提示只出现一次，无需回复；如用户问到记忆为什么"不见了"，以上是要点。
